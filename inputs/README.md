# 输入数据 / Inputs

Raster data are not included. Prepare monthly series with matching grids and aligned dates.
Use consistent, zero-padded year/month filenames, such as `2004.01.tif`.

包内不附带栅格。请准备网格一致、月份对齐的月尺度序列，文件名需包含可提取的年月，
例如 2004.01.tif。运行前应记录各输入的单位、时段、分辨率、坐标系、缺失值及预处理方法。

```text
inputs/
  SPEI_01/               # 月尺度 SPEI
  SSI_01/                # 月尺度 SSI
  DSI/                   # 月尺度 DSI
  SIF_standard/          # 标准化 SIF
  PT/                    # 外部准备的传播阈值栅格
  static_weights_6dp.csv  # Python 脚本生成的静态熵权
```

## Propagation thresholds / 传播阈值输入

Supply the following eight rasters in `inputs/PT/`. Thresholds are external inputs;
their estimation is outside the scope of the shared code. The four numbered levels
correspond to mild, moderate, severe, and extreme drought, respectively.

请在 inputs/PT 中准备以下八个栅格。传播阈值作为外部输入，估计过程不在本次共享代码范围内。
编号 1、2、3、4 依次对应轻度、中度、重度和极端干旱。

| Channel / 通道 | Filenames / 文件名 |
| --- | --- |
| SPEI → SSI | `Threshold_SPEI-SSI1.tif`, `Threshold_SPEI-SSI2.tif`, `Threshold_SPEI-SSI3.tif`, `Threshold_SPEI-SSI4.tif` |
| SSI → DSI | `Threshold_SSI-DSI1.tif`, `Threshold_SSI-DSI2.tif`, `Threshold_SSI-DSI3.tif`, `Threshold_SSI-DSI4.tif` |

All threshold rasters must match the monthly inputs in extent, resolution, and coordinate reference system.
Record the threshold derivation method and provenance with the input data.

所有阈值栅格须与月尺度数据具有一致的范围、分辨率和坐标系；请随输入记录阈值的计算方法与来源。

## Sources / 来源

The input datasets and their sources are described in the data sources section of the main text.
The static weights are generated by `static_weights.py` and match the constants in `sacdi_final_U30.R`.

输入数据及其来源详见正文的数据来源部分。静态权重由 static_weights.py 生成，与 R 脚本常量一致。
